# Stellar Burgers :hamburger:

Космический конструктор бургеров с возможностью оформления заказов в реальном времени.

## 🚀 О проекте

Stellar Burgers - это современное React-приложение для заказа бургеров с интерактивным конструктором. Пользователи могут собирать бургеры перетаскиванием ингредиентов, оформлять заказы и отслеживать их статус.

## ✨ Функциональность

### 🍔 Конструктор бургеров

- **Drag & Drop** - перетаскивание ингредиентов в конструктор
- **Добавление по клику** - альтернативный способ добавления ингредиентов
- **Подсчет стоимости** - автоматический расчет итоговой цены
- **Валидация заказа** - проверка наличия булки и ингредиентов

### 👤 Личный кабинет

- **Регистрация и авторизация** - система аутентификации пользователей
- **История заказов** - просмотр всех выполненных заказов
- **Редактирование профиля** - изменение данных пользователя

### 📊 Лента заказов

- **Real-time обновления** - WebSocket соединение для live-обновлений
- **Статусы заказов** - отслеживание выполнения заказов
- **Детали заказа** - подробная информация о каждом заказе

## 🛠 Технологии

- **Frontend:** React 18, TypeScript, Redux Toolkit
- **Роутинг:** React Router v6
- **Drag & Drop:** React DnD
- **Стили:** CSS Modules
- **API:** WebSocket, REST API
- **Сборка:** Webpack
